# FitLog — Workout Library

FitLog is a responsive workout library and planning web application built for people who want to browse workouts, create a daily workout plan, save exercises for later, and track completed workouts. It provides a clean, dark-themed interface with workout details, sorting, plan management, and local data persistence.

## 🚀 Technologies Used

- Next.js
- React
- Tailwind CSS
- JavaScript
- Lucide React
- REST API
- LocalStorage
- Vercel

## ✨ Key Features

1. **Workout Library**
   - Browse all available workouts in a responsive grid.
   - Each workout card displays the exercise image, category, name, equipment, duration, calories, and rating.

2. **Workout Details**
   - View detailed information about each workout.
   - Includes exercise instructions, specifications, tags, and workout information.

3. **Today's Plan**
   - Add workouts to today's workout plan.
   - View total planned duration and estimated calories.
   - Mark workouts as completed or remove them from the plan.

4. **Saved Workouts**
   - Save workouts for later.
   - Easily access and manage saved workouts from the My Plan section.

5. **Sorting & Responsive Design**
   - Sort workouts by duration, calories, or rating.
   - Fully responsive design for mobile, tablet, and desktop devices.
